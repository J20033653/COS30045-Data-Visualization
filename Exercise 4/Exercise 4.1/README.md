# Exercise 4.1 – Draw SVGs

A house and garden drawn with SVG shapes, all on `index.html`.

It uses `rect`, `circle`, `ellipse`, `line`, `polyline`, `polygon`, `path` (the chimney smoke), `text` and `g`. The two windows sit in a `<g>` that sets their fill and stroke once, and each window is moved into place with `translate()`.
