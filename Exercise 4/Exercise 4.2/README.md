# Exercise 4.2 – D3 and a responsive SVG

Starts from the Exercise 0.2 site. D3 code lives in its own file, `assets/js/main.js`, separate from `script.js`.

- `style.css` has a `.responsive-svg-container` class that centres the chart and caps it at 1200px wide.
- `index.html` has a `<div class="responsive-svg-container">` and loads D3 and `main.js`.
- `main.js` adds an `<svg>` to that div with a `viewBox` so it scales with the window, plus a temporary border and a blue test rectangle.

The earlier demo code (styling the heading, appending a paragraph) was removed.
