# Exercise 4.7 – Labels with groups

Each bar is now a `<g>` group holding the bar, the brand name on the left and the count on the right. The group is moved to its row with `translate()`, so the bar and both labels can use positions relative to it.

The bars start at x=100 to leave space for the brand names. The scales are the same as 4.6.
